# 3대 리그 전술 리포트 (EPL · 라리가 · 분데스리가)

매일 아침 새로 끝난 경기를 조사해 경기별 자료를 쌓고, Claude 안의 리포트 페이지를 업데이트합니다.

## 경기마다 모으는 자료

| 항목 | 내용 |
|---|---|
| 명단 | 선발 11명(포지션·등번호), 벤치 명단, 교체 기록 |
| 결장 | 부상·징계·질병으로 빠진 선수와 사유 |
| 주요 전술 | 압박(높이·강도), 내려앉음(수비 블록 높이), 미들싸움(중원 경합 결과) |
| 공격·수비 | 공격 전술, 수비 전술, 공격 루트(왼쪽·중앙·오른쪽 비중) |
| 공격 지표 | 총공격, 위험한공격, 슛, 유효슛, 골, 점유율, xG (출처가 확인된 값만) |
| 포지션별 기록 | 선수별 출전 시간, 골, 도움, 슛, 유효슛, 키패스, 태클, 가로채기, 선방, 평점 |
| 경기 흐름 | 시간대별(0-15 … 76-90+) 흐름과 주요 장면 |

팀마다 등록 선수단과 시즌 전술 요약도 만듭니다.

## 넓게 수집하는 규칙 (rules.py)

통계 사이트 한두 곳에서 멈추지 않도록 프로그램이 직접 검사합니다.

- 8개 범주: 공식 자료, 현지어 언론, 해외 언론, 전술 분석·개인 블로그, 유튜브, 팬 커뮤니티, 통계 사이트, 인터뷰
- 기준: 검색 12회 이상, 정보를 가져온 사이트 8곳 이상, 범주 6개 이상, 블로그·유튜브·커뮤니티는 필수
- 검색어는 현지어·영어·한국어 세 언어로
- 실제 검색·열람 기록에 없는 주소는 출처로 인정하지 않음
- 기준에 못 미치면 빠진 범주를 다시 조사시킴 (최대 2번). 그래도 못 채우면 페이지에 '수집 기준 미달'로 표시

유튜브는 영상을 직접 볼 수 없어서 제목·설명·검색 요약에서 정보를 얻습니다.

## 순서와 예산

1. 최근 10일 안에 끝난 경기 (가장 최근 경기부터)
2. 팀별 등록 선수단 (60일마다 새로 확인)
3. 지난 경기: 1라운드부터 차례로. 이번 달 남은 기간의 최신 경기 몫을 남겨 두고 남는 예산으로만 진행
4. 새 기록이 생긴 팀의 시즌 전술 요약

이번 달 사용액이 `MONTHLY_BUDGET_USD`에 닿으면 멈추고 다음 달에 이어서 합니다. API 크레딧이 떨어져도 멈췄다가 이어집니다.

## 파일

| 경로 | 내용 |
|---|---|
| `run.py` | 실행 순서, 예산 관리 |
| `rules.py` | 수집 규칙과 검사 |
| `llm.py` | Claude API 호출, 비용 계산 |
| `schema.py` | 경기 기록 형식 |
| `fixtures.py` | 경기 일정·결과 (OpenLigaDB, football-data.org) |
| `site_build.py` | 페이지용 데이터, CSV 만들기 |
| `site/index.html` | 리포트 페이지 |
| `data/<리그>/matches/` | 경기별 원자료 (수집 노트, 출처, 정리된 기록) |
| `exports/` | 엑셀로 여는 CSV: 경기별 팀 지표(`_matches`), 선수 기록(`_players`), 명단·결장(`_lineups`) |

리그 코드: `PL` 프리미어리그, `PD` 라리가, `BL1` 분데스리가

## 설정 (워크플로 파일의 `env:`에 추가)

| 이름 | 기본값 | 설명 |
|---|---|---|
| `LEAGUES` | `PL,PD,BL1` | 수집할 리그 |
| `MONTHLY_BUDGET_USD` | `190` | 한 달에 쓸 최대 API 비용(달러) |
| `MODEL` | `claude-sonnet-5-5` | 사용할 모델 |
| `MIN_SEARCHES` | `12` | 경기당 최소 검색 횟수 |
| `MIN_DOMAINS` | `8` | 정보를 가져와야 하는 최소 사이트 수 |
| `MIN_CATEGORIES` | `6` | 채워야 하는 최소 범주 수 (8개 중) |
| `REQUIRED_CATEGORIES` | `D,E,F` | 반드시 들어가야 하는 범주 (블로그, 유튜브, 커뮤니티) |
| `MAX_FOLLOWUPS` | `2` | 기준 미달일 때 다시 조사시키는 횟수 |
| `MAX_SEARCHES_PER_TURN` | `16` | 한 번 조사할 때 검색 최대 횟수 |
| `MAX_FETCHES_PER_TURN` | `6` | 한 번 조사할 때 페이지 열람 최대 횟수 |
| `MAX_RUN_MINUTES` | `300` | 이 시간이 지나면 새 경기를 시작하지 않음 |

## 필요한 Secret

- `ANTHROPIC_API_KEY`: Claude API 키
- `FOOTBALL_DATA_TOKEN`: football-data.org 무료 토큰 (EPL·라리가 경기 목록용. 분데스리가는 없어도 됨)
